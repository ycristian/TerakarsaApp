Mockup Prompt 70 — Absensi RFID

Referensi visual untuk prompt_70_absensi_rfid.md. Markup di bawah adalah HTML + inline style murni, tanpa framework — salin struktur, ukuran, warna dan hierarki teksnya saat membuat .razor, jangan merancang ulang dari nol.

  • Layar gate dirancang pada 1280 × 853 CSS px = tablet 1920 × 1280 dengan skala tampilan Windows 150%.
  • Layar admin dirancang pada 1440 × 900. Implementasi nyatanya memakai Bootstrap seperti halaman TMOS lain — pakai mockup ini sebagai acuan tata letak dan isi kolom, bukan sebagai CSS yang disalin mentah.
  • Target sentuh di layar gate minimal 48 px; baris daftar karyawan 64 px.
  • Font: IBM Plex Sans; UID kartu selalu IBM Plex Mono dengan letter-spacing: 0.08em.
  • Semua teks sudah bahasa Indonesia dan boleh dipakai apa adanya.
  • Data di mockup adalah contoh. Nama, kode, jam dan UID diganti data nyata dari SP.
